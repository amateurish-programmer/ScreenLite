# ScreenLite 使用说明

## 打开

将 ZIP 完整解压到一个可写文件夹，双击 `ScreenLite.exe`。无需安装 Python。
首次启动显示主面板；关闭窗口后留在右下角托盘，下次启动默认后台运行。
如果托盘图标被 Windows 收起，请在任务栏的小箭头中查找。

不要单独移动 EXE。`_internal`、`bin` 和 `LICENSES` 文件夹需要保留。

## 截图

1. 按 **Ctrl+Alt+A**，拖出区域。
2. 拖动边缘或八个控制点调整大小，拖动区域内部改变位置。
3. 方向键微调，Shift+方向键加速；Enter 确认，Esc 取消。
4. 截图默认自动复制，浮动工具条可直接保存；点击“更多选项”调整尺寸、PNG/JPEG/WebP 格式和画质。

PNG 保留完整画质；JPEG 通用；WebP 通常适合缩小文件。
已有文件不会被覆盖，需要选一个新文件名。

## 录屏

1. 按 **Ctrl+Alt+R**，选择区域并按 Enter。
2. 准备录制后默认倒计时 3 秒开始，也可在设置中改为立即开始。准备期间可再次按录屏快捷键取消，倒计时中也可按 Esc。
3. 再按 **Ctrl+Alt+R** 停止。浮动控制条和托盘提示显示录制时间。浮动控制条会请求系统排除在录制画面外；系统不支持时自动隐藏，仅使用托盘。
4. 选择原尺寸、1080p、720p 或 480p，以及画质，导出 MP4。

首版录制画面，可在设置中选择是否包含鼠标，不录声音；录制过程中打开的窗口如果位于选区内也会被录入。
可从托盘打开主面板查看时间或停止录制。录制时通过托盘“退出”，会先保存素材再关闭。

## 压缩已有文件

点击“压缩已有文件”，选择图片或视频，设置尺寸和画质后另存。
视频转码显示进度，点击“取消导出”可以停止；原文件会保留。
有些视频本来就很小，重新编码可能变大，完成提示会显示实际大小。

## 设置与恢复

- 设置中可改截图/录屏快捷键、15/30/60 帧、默认画质、自动复制、倒计时、鼠标录制和保存位置。
- 快捷键被占用时会提示更换；也可以直接使用主面板按钮。
- 默认导出位置是程序文件夹的 `exports`。
- 停止录制后如果暂时不导出，原始素材保留在 `data/recordings`，从托盘“打开录制素材”找到，再用“压缩已有文件”导出。
- 成功导出本次录屏后，程序会清理对应临时素材。外部导入的原文件始终保留。
- 如果录制异常中断，错误提示会给出保留素材的位置。部分异常素材可能无法恢复。
- `data/settings.json` 是设置，`data/screenlite.log` 是错误日志。所有素材和配置都保存在本机。

## 首版边界

仅支持 Windows x64；每次在一块屏幕内选择区域。单屏录制会探测可用的硬件编码，失败自动切换兼容模式；
高分辨率或 60 帧录制会增加 CPU 占用，日常推荐 30 帧。
当前包为本地测试版，混合缩放多显示器、锁屏/睡眠、远程桌面和长时录制仍需要进一步实测。
