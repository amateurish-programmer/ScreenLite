一个免安装的 Windows 截图、区域录屏和媒体压缩小工具。以快捷键进入，以简单的导出结束，让桌面保持安静。

Python 3.12 · PySide6 Widgets · Windows 10 / 11 x64

01 / PRODUCT

产品与范围

用户原始需求：免安装、轻量化、后台运行；快捷键触发截图或录屏；选区可调整；图片可导出不同像素尺寸，视频可导出不同分辨率；支持图片与视频压缩；界面简约舒适。

来源边界：引用对话“规划截屏录屏工具”的完整读取被网页验证阻断。目前只获得用户提供的原始请求和助手预览，预览截断在截图键盘操作处。本文件是依据可见对话整理的开发规格，并非完整对话逐字转录。未见部分由本项目补充设计，不冒称原对话结论。

已确认方案

暂名 ScreenLite，托盘常驻，默认 Ctrl+Alt+A 截图、Ctrl+Alt+R 开始或停止录屏；八点调整选区、拖动移动、方向键微调、Enter 确认、Esc 取消。技术候选是 Python、PySide6、MSS、Pillow、FFmpeg、Win32 热键、JSON 配置。

首版补充约定

无声录屏；同一块显示器内选择区域，不允许横跨不同缩放的屏幕；截图冻结桌面后选区；关闭主窗口保留托盘，显式退出才结束。支持已有图片与视频压缩。暂不加入绘图标注、OCR、云同步、自动更新、开机自启或录音。

02 / EXPERIENCE

从快捷键到文件，保持短路径

快捷键→框选 / 调整→确认→预览与导出
场景交互规则
首次启动展示轻量主面板和快捷键提示；后续后台启动只显示托盘。热键冲突给出可操作提示。
截图选区屏幕淡暗，选区保留亮度；八个拖动点、边缘光标、整块移动；标注物理像素宽高。
键盘方向键移动 1 个逻辑像素，Shift+方向键移动 10 个；Enter 确认；Esc 取消。高 DPI 下标签显示实际物理像素。
图片导出原图预览，设置输出尺寸、格式、质量；复制结果至剪贴板或另存；失败保留预览。
录屏选区确认后 3 秒倒计时；录制中托盘状态和计时清晰；相同热键停止；停止后设置导出尺寸与压缩档位。
压缩选择已有文件，另存新文件；显示进度、取消按钮和完成大小；源文件不修改。

视觉：暖白背景、深色文字、柔和青绿色重点按钮；中文短文案；不堆叠复杂参数。编码细节放在开发文档，用户界面用“清晰、均衡、小体积”。

03 / ARCHITECTURE

界面、捕获、导出分离

模块实现责任
应用PySide6-Essentials / Widgets主面板、托盘、状态机、单实例和退出协调
选择区域每屏独立覆盖窗口冻结截图、选框与坐标换算，不跨屏拼接
桌面截图MSS + Pillow获取原始像素，编辑预览，缩放编码
录屏FFmpeg 子进程独立进程捕获编码，UI 不逐帧处理
热键RegisterHotKey / ctypes系统级热键、MOD_NOREPEAT、防重复触发、注销恢复
存储JSON + 本地文件程序目录 data/ 保存配置、日志、恢复素材

原方案倾向 ddagrab + h264_mf。工程实现必须验证 DXGI 输出索引与显示器映射；不能把 Qt/MSS 的显示器序号当成 DXGI 序号。首版默认使用 gdigrab + libx264 兼容路径，并提供显式映射的 ddagrab 命令构造能力。该性能取舍记录在交付说明。

DPI：进程尽早启用 Per-Monitor V2；选区使用当前屏幕逻辑坐标，截图与 FFmpeg 使用物理桌面坐标。分别测试 100%、125%、150% 和负坐标副屏；未实测项目明确标记。

状态流：空闲 → 选区 → 倒计时 → 录制 → 收尾 → 导出 → 空闲。重复快捷键、关闭窗口、退出和进程异常都需要按状态处理。

04 / OUTPUT

明确的输出与压缩参数

输出清晰均衡 · 默认小体积
JPEG质量 92质量 85质量 72
WebP质量 90质量 80质量 65
PNG无损优化；档位不降低画质，不保证文件一定变小
MP4 / H.264CRF 18CRF 23CRF 28

视频默认 30 fps，可选 15/60 fps；导出使用 libx264 + medium + yuv420p + faststart。已有视频保留可选音轨并编码 AAC；新录制不采集音频。转码默认不放大、保持比例，视频宽高修正为偶数。

图片尺寸：原始、50%、1080p 范围、720p 范围、自定义宽度。视频尺寸：原始、1080p、720p、480p。压缩大小依赖画面复杂度，不承诺固定压缩比；导出不能覆盖原始文件。

05 / RELIABILITY

失败时，优先保留成果

  • 临时录制写入 MKV，正常结束再导出 MP4；异常终止保留可恢复的临时文件。
  • 压缩写入同目录临时文件，成功后发布到新目标；取消清理未完成的导出，不删原始录制。
  • FFmpeg 使用参数数组，不使用 shell 字符串；路径含空格、中文必须可用。
  • 重型任务不阻塞界面；退出时先优雅停止录制，必要时保留恢复文件。
  • 配置原子替换，损坏文件保留备份；目录不可写明确报错。
  • 不联网上传截屏、视频、配置或日志。开发仓库不收录真实桌面素材。
  • 单实例避免重复热键、并行写配置；热键设置失败应回滚之前注册。

07 / DELIVERY

便携目录与开发约定

交付结构：ScreenLite.exe、_internal/、bin/ffmpeg.exe、licenses/、docs/。解压到可写目录运行，无需安装 Python。运行时生成 data/。

原方案建议 Nuitka / pyside6-deploy；首版使用 PyInstaller onedir 以便本机完成可重复打包验证。保留独立动态库，收录依赖和 FFmpeg 的许可证、版本与来源。Python + Qt 的便携包不能按原生几 MB 工具估算，最终公布实际 ZIP 和解压大小。

本项目私有仓库：amateurish-programmer/ScreenLite。阶段提交使用真实本机 Git 身份；本地 SSH 签名不等同于 GitHub Verified 身份认证。
